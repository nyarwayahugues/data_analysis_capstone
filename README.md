# E-commerce Sales and Customer Analysis

## Project Overview
This project analyzes e-commerce transaction data to understand revenue trends, product performance, customer behavior, and customer segments.

## Objectives
- Clean and validate raw transaction data
- Analyze sales trends over time
- Identify top-performing products and cities
- Understand customer behavior
- Segment customers using RFM analysis
- Provide business recommendations

## Dataset
The dataset contains:
- order_id
- order_date
- customer_id
- city
- product_name
- category
- quantity
- unit_price
- revenue
- payment_method

## Tools Used
- Python
- pandas
- matplotlib
- Jupyter Notebook

## Project Steps
1. Data loading
2. Data cleaning
3. Exploratory data analysis
4. RFM customer segmentation
5. Business insights and recommendations

## Key Insights
- Revenue varied across months
- A few products generated most of the revenue
- Some cities outperformed others
- Customer segmentation identified VIP and at-risk customers

## Recommendations
- Prioritize high-performing products
- Run retention campaigns for at-risk customers
- Reward loyal customers
- Increase focus on underperforming cities

## Files
- `notebooks/analysis.ipynb`: full analysis
- `data/processed/`: cleaned and derived data
- `reports/`: saved charts
